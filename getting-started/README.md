# Getting Started with Wazuh

Welcome to the Wazuh Knowledge Center! This section provides a comprehensive introduction to the Wazuh platform, including its architecture, capabilities, and common use cases. Whether you are new to Wazuh or looking to expand your knowledge, this guide will help you get started.

## Platform Overview

The Wazuh platform is a powerful open source security solution that provides unified XDR and SIEM protection for endpoints and cloud workloads. It is designed to help organizations prevent, detect, and respond to threats in real-time.

### Key Components

- **Wazuh Agent**: Deployed on endpoints to collect security data.
- **Wazuh Server**: Analyzes data from agents and triggers alerts.
- **Wazuh Indexer**: Indexes and stores security data for analysis.
- **Wazuh Dashboard**: Provides a web interface for data visualization and analysis.

For a detailed exploration of the platform, see the [Platform Overview](platform-overview/) section.
